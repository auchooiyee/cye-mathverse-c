    INCOMING TRANSMISSION

    A little robot.
    A big escape.

    Help Pip escape a locked cyber-lab. Turn number-base digits into power, repair six sectors and open the master vault.

    1. Read the signal and its base.
    2. Set each place-value chip using + / − or type a code.
    3. Connect the circuit. Learn, retry and keep going.

    Hints and retries are always free. Progress stays in this browser. Nothing is sent to a teacher or server.

    FIELD GUIDE

    Digits are your tools.

    In base 2, the places from right to left are 1, 2, 4, 8… Each digit must be smaller than the base.

    1012 = 1 × 4 + 0 × 2 + 1 × 1 = 510

    Use the chips to build the requested value. Connect circuit tests it. A correct signal restores a lock; two locks open a sector.

    Guided mode shows live totals for exploration. Independent mode hides them until checking. Using a hint or seeing a guided preview is recorded, but never reduces the 100 XP completion reward.

    玩法：读清楚进制，用 + / − 调整数位，让电力等于目标，再连接电路。答错没关系，可以无限重试！

    Bina kod menggunakan nilai tempat. Digit mesti lebih kecil daripada asas. Cuba lagi tanpa kehilangan XP.

    Keyboard: Tab between controls; Enter/Space activates a button. Or type the whole code. No timer or sound is required.
